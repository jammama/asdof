# 자가진단 '그렇다' 전체 체크 북마크렛

서울챌린지 자가진단(`/letsdoseoul/040201/selfdgnss/...`)처럼 라디오 보기로 된 설문에서
모든 문항의 긍정 보기('그렇다')를 선택하고, 이어서 '다음'/'제출' 버튼까지 눌러준다.

## 파일
- `check-yes.js` — 읽기용 원본 소스
- `bookmarklet.txt` — 북마크 주소창에 넣는 한 줄(`javascript:` 포함)

## 설치
1. 크롬 북마크바에서 우클릭 → **페이지 추가**
2. 이름: `그렇다 전체체크`
3. URL: `bookmarklet.txt` 내용 전체를 붙여넣기
4. 설문 페이지에서 북마크 클릭 → 상단에 `✅ N개 문항 체크 → '다음' 클릭` 토스트

## 동작
### 1) 체크
- 페이지 안 **모든 라디오 그룹(name 기준)** 을 훑어 라벨 텍스트로 긍정 보기를 고른다.
  문항 수·이름에 의존하지 않으므로 다음 페이지에서도 같은 북마크를 그대로 쓴다.
- 우선순위: `그렇다`(정확일치) > `매우 그렇다` 등 부분일치 > `예/네/동의`.
  `아니오 / 그렇지 않다 / 없다 / 모름` 계열은 제외.
- 라벨로 판단이 안 되고 보기가 2개뿐이면 `value="1"`을 대안으로 선택.
- 이미 선택된 그룹은 건드리지 않고, 판단 불가 그룹은 토스트에 name을 표시한다.
- `display:none`으로 숨은 문항(heaboja의 2페이지 6~12번)도 함께 체크된다.

### 2) 진행 버튼 클릭
- 마지막으로 체크한 문항에서 DOM을 거슬러 올라가며 **가장 가까운, 화면에 보이는**
  버튼을 찾는다(푸터·네비의 '다음글' 같은 오탐 방지).
- '다음/계속/next'을 먼저 찾고, 없으면 '제출/완료/결과 보기/확인하기'를 누른다.
  '이전/뒤로/취소/목록/처음/다시/닫기'는 절대 누르지 않는다.
- 사이트의 change 핸들러가 끝난 뒤 눌리도록 150ms 뒤에 클릭한다.
- 버튼을 못 찾으면 체크만 하고 `· 진행 버튼 없음`을 표시한다.

heaboja 기준 **북마크 1번 클릭 → 12문항 체크 + '다음'**, **2번 클릭 → '제출'** 로 끝난다.
(2번째 클릭은 실제 폼 전송 `POST /letsdoseoul/040201/selfdgnss/save.do` 까지 진행됨)

## 검증
`heaboja.html`을 UTF-8로 로컬 서빙하고 사이트의 jQuery 핸들러를 동일 동작으로 재현해 크롬에서 실행:
- 1회차: `✅ 12개 문항 체크 → '다음 (1/2)' 클릭`, testpage1 숨김/testpage2 표시 확인
- 2회차: `✅ 0개 문항 체크 (이미 선택됨 12) → '제출 (2/2)' 클릭`, 제출 값 12개 전부 `1`(그렇다) 확인
- 5점 척도(전혀 그렇지 않다~매우 그렇다)·예/아니오 형태를 모의 삽입한 경우 각각 `그렇다`, `예` 선택 확인
