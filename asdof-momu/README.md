# asdof-momu — 뭐 먹었지?

회사에서 식당 갈 때마다 **뭘 먹었는지** 남겨 두는 기록 앱.
카카오맵으로 식당을 찾아 등록하고, 갈 때마다 메뉴·평점·가격·메모를 쌓는다.

- 주소: https://momu.asdof.xyz
- 관리자 비밀번호: `asdof1234` (등록·수정·기록 작성에 필요. 읽기는 누구나)
- DB 없음 — 서버의 `/var/lib/asdof-momu/data.json` 한 파일이 전부

## 기능

| 기능 | 위치 |
|---|---|
| 카카오맵 음식점 검색 | **식당 찾기** 탭 — 카카오 Places(`FD6` 음식점) 키워드 검색, 지도 중심 5km 우선 |
| 식당 등록 | 검색 결과의 **등록** 버튼 → 이름·주소·좌표 자동 프리필, 카테고리 자동 추정 |
| 카테고리 분류 | 한식/중식/일식/양식/분식/고기/치킨/카페·디저트/술집/아시안/패스트푸드/기타 (+ 직접 입력값도 필터에 자동 노출) |
| 등록 식당 검색 | **내 기록** 탭 — 이름·**먹은 메뉴**·주소·메모 통합 검색 |
| 거리 검색 | 기준점에서 300m/500m/1km/2km/5km 반경 필터 + 가까운 순 정렬. 기준점은 **회사(팁스타운 S5, 서울 강남구 역삼로 177)** 가 기본이고 `🏢 회사 / 📍 내 위치 / 지도 중심` 으로 바꾼다. 회사 기준일 때는 지도를 움직여도 거리가 그대로다 |
| 메뉴 등록 | 식당 등록/수정 폼의 **메뉴** 칸에 쉼표로 구분해 입력하면 배열로 저장. 등록 직후 그 식당 상세가 열린 채로 남는다 |
| 카카오에서 메뉴 가져오기 | 등록/수정 폼의 버튼 하나로 카카오에 등록된 메뉴 전체를 메뉴 칸에 채운다. 이미 적어 둔 메뉴는 유지하고 없는 것만 덧붙인다. 가격·평점·리뷰수는 힌트로만 보여 준다(저장 안 함). `kakao_id` 가 있는 식당만 가능 |
| 메뉴별 별점 | 상세 화면의 메뉴 목록에서 별을 누르면 **저장 버튼 없이 바로 저장**. 같은 별을 다시 누르면 미평가로 지워진다. 방문 평점이 없는 식당은 목록에도 메뉴 평균 별점이 뜬다 |
| **오늘 뭐?** (추천) | 점심에 "뭐 먹지" 를 끝내는 탭. 거리·최근 방문 제외·카테고리로 후보를 좁히고 **룰렛**으로 하나 뽑는다. 후보 목록에서 직접 골라도 된다 |
| 방문 기록 | 날짜·메뉴(여러 개)·평점(0~5)·1인 가격·같이 간 사람·메모. 식당별 방문 횟수/평균 평점/평균 가격 집계 |

정렬: 최근 방문 · 가까운 순 · 이름 · 방문 많은 순 · 평점

## 구조

```
main.go              Go 파일서버 (정적 파일 + JSON API, 의존성 0)

nginx-momu.conf      nginx vhost
deploy.sh            배포
```

## API

읽기는 공개, **쓰기는 `X-Admin-Password` 헤더 필수**.

| 메서드 | 경로 | 설명 |
|---|---|---|
| `GET` | `/healthz` | `ok <식당 수>` |
| `POST` | `/api/auth` | `{"password":"…"}` → 비밀번호 검증 (200/401) |
| `GET` | `/api/restaurants` | `{"restaurants":[…]}` 전체 (방문 기록 포함) |
| `POST` | `/api/restaurants` | 식당 등록. `kakao_id` 중복이면 409 |
| `PUT` | `/api/restaurants/{id}` | 식당 수정 |
| `DELETE` | `/api/restaurants/{id}` | 식당 + 방문 기록 삭제 |
| `PUT` | `/api/restaurants/{id}/menus/{mid}` | 메뉴 별점만 갱신 (`{"rating":0~5}`) — 별 클릭이 바로 호출 |
| `GET` | `/api/kakao/place/{kakao_id}` | 카카오 장소의 메뉴·평점 조회 (프록시). `{menus:[{name,price}], score, reviews}` |
| `POST` | `/api/restaurants/{id}/visits` | 방문 기록 추가 |
| `PUT` | `/api/restaurants/{id}/visits/{vid}` | 방문 기록 수정 |
| `DELETE` | `/api/restaurants/{id}/visits/{vid}` | 방문 기록 삭제 |

방문 기록은 저장 시 날짜 내림차순으로 정렬해 둔다(클라이언트가 `visits[0]`을 최근 기록으로 취급).
문자열 길이·평점 범위는 서버에서 clamp 한다.

`menus` 는 `["짜장면","탕수육"]` 문자열 배열과 `[{"name":…,"rating":…}]` 객체 배열을 모두 받는다.
등록/수정 폼은 이름만 보내고, **이름이 같은 기존 메뉴의 별점은 서버가 살려 준다** — 메뉴를 추가·삭제해도 점수가 날아가지 않는다.

## 오늘 뭐? (룰렛)

후보 조건 — 기본값은 **회사 500m · 최근 1주 방문 제외**(점심에 걸어갈 만하고, 같은 집 연달아 가지 않게):

| 조건 | 값 |
|---|---|
| 거리 | 전체 / 300m / 500m / 1km / 2km / 5km — 기준점은 `기준점` 설정을 그대로 따른다(기본 회사) |
| 최근 방문 제외 | 안 뺌 / 3일 / 1주 / 2주 / 한달 — `visits` 의 마지막 날짜로 계산 |
| 카테고리 | 등록된 카테고리만 개수와 함께 노출(다중선택) |

룰렛은 이름이 바뀌며 점점 느려지고 **마지막에 화면에 뜬 곳이 그대로 결과**다
(따로 뽑아 두고 애니메이션만 돌리는 게 아니라 표시된 값이 결과 — 눈속임이 없다).
간격은 `42 + 0.75n²`ms, 총 25~27틱으로 **4.7~5.7초**.

결과 카드에는 거리·마지막 방문 시점·별점과 함께 **별점 높은 메뉴가 먼저** 나온다(뭘 시킬지도 정해 준다).
`상세` / `＋ 방문 기록` / `길찾기` / `🎲 다시` 로 바로 이어진다.

> 브라우저가 백그라운드일 때는 Chrome 이 `setTimeout` 을 1초로 스로틀링하므로 룰렛이 25초쯤 걸린다.
> 탭이 보이는 상태에서는 정상(5초 안팎). 자동화로 시간을 재면 이 때문에 어긋난다.

## 카카오 장소 프록시

`GET /api/kakao/place/{kakao_id}` 는 서버가 카카오 내부 API 를 대신 호출한다.

```
GET https://place-api.map.kakao.com/places/panel3/{id}
  pf: web                                  ← 없으면 406
  Referer: https://place.map.kakao.com/    ← 없으면 406
  User-Agent: <브라우저 UA>
```

브라우저에서 직접 부르면 CORS 로 막히므로 프록시가 필요하다. 이 경로는 **관리자 인증을 요구한다** —
인증이 없으면 누구나 우리 서버를 통해 외부 요청을 날릴 수 있는 열린 프록시가 된다.
장소 id 는 숫자만 허용하고(`isDigits`), 응답은 1MB 로 제한하며 타임아웃은 8초다.
카카오가 가격을 모르는 메뉴는 `-1` 로 주는데 `price: 0` 으로 정규화한다.

문서화되지 않은 내부 API라 카카오가 헤더 요구사항이나 응답 구조를 바꾸면 502 가 난다.
그때는 `kakaoPanel` 구조체와 헤더 세 줄만 고치면 된다.

## 배포

```bash
./deploy.sh                 # 코드/화면 갱신 (data.json 은 유지)
./deploy.sh --nginx         # + nginx vhost + Let's Encrypt (최초 1회)
./deploy.sh --pull-data     # 배포 전 서버 data.json 을 backup/ 으로 내려받기
```

- 앱은 `127.0.0.1:8790` 에만 listen, nginx 가 앞단에서 프록시
- 비밀번호는 `/etc/asdof-momu.env` (`ADMIN_PASSWORD=…`). 바꾸려면 `ADMIN_PASSWORD=새값 ./deploy.sh`
- 회사 좌표(거리 기준점 + 첫 지도 중심)는 `static/js/app.js` 의 `OFFICE` 상수. 사무실이 옮겨가면 여기만 고치면 된다
- 카카오맵 JS 키는 `static/index.html` 에 인라인. **momu.asdof.xyz 가 카카오 개발자 콘솔의 웹 플랫폼 도메인에 등록돼 있어야** 지도가 뜬다 (localhost 는 미등록이라 로컬에서 지도 테스트 불가)
